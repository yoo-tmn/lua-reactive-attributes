# Lua Reactive Attributes
This library is designed for Rogue-Like and RPG attribute systems. Initially developed for Warcraft III. However, I believe it can be used in other applications as well, because it is independent and written in pure Lua.

Main focus of Reactive Attributes is to provide easy API for data modifying, e.g. unit stats or game state. It takes care of attributes dependencies, recalculation logic, batching and memory optimization. And also provides reactivity and API for custom calculations.


# What you can do with it?
Using this you can implement bunch of most common modifier patterns spread among many RPG games.
You can either create plain +n modifiers and multiplicative, progressive, conditional and other complex modifiers.
